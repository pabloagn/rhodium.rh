## Core Technologies

### NixOS

The foundation of Rhodium. A declarative, reproducible Linux distribution.

- Website: [nixos.org](https://nixos.org)
- Repository: [github.com/NixOS/nixpkgs](https://github.com/NixOS/nixpkgs)

### Home Manager

User-level configuration management for NixOS.

- Repository: [github.com/nix-community/home-manager](https://github.com/nix-community/home-manager)

### Niri

Scrollable-tiling Wayland compositor.

- Repository: [github.com/YaLTeR/niri](https://github.com/YaLTeR/niri)
- Nix Flake: [github.com/sodiboo/niri-flake](https://github.com/sodiboo/niri-flake)

## Tools

### Neovim

The editor at the heart of the development experience.

- Website: [neovim.io](https://neovim.io)

### Yazi

Terminal file manager with async I/O.

- Repository: [github.com/sxyazi/yazi](https://github.com/sxyazi/yazi)

### Fish

User-friendly shell.

- Website: [fishshell.com](https://fishshell.com)

### Kitty

GPU-accelerated terminal emulator.

- Website: [sw.kovidgoyal.net/kitty](https://sw.kovidgoyal.net/kitty)

### Waybar

Customizable Wayland bar.

- Repository: [github.com/Alexays/Waybar](https://github.com/Alexays/Waybar)
